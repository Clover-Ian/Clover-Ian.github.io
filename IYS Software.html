IYS PDF

A light, fast PDF editor. Write on the page, add text, draw shapes, and save a PDF that looks the same everywhere.

Version 0.1 · macOS 26+ · Apple Silicon

Mark it up.

Pen, highlighter, and shapes — lines, arrows, rectangles, ellipses and true circles. Every mark can be moved, resized, rotated and erased afterwards.

Add the words.

Click anywhere and type. Every text box keeps its own font, size and colour, and you can double-click it to edit it again.

Clean when you save.

Everything you draw is merged into the page on save, so the file looks identical in Preview, on iPhone, or on Windows.

IYS Archiver

A quick, native archiver. Everything is free except the Cyberpunk theme.

Version 0.1 · macOS 26+ · Apple Silicon

Drop it in.

Files to compress, archives to extract, or both at once — mixed drops are routed by type.

7-Zip inside.

A native window around the real 7-Zip engine. RAR, 7Z, CAB, WIM, ISO and more open straight from it.

Everything free.

Twelve formats, AES-256, split volumes and every extraction — no key needed. Only the Cyberpunk theme is Pro.
