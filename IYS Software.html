IYS PDF

A light, fast PDF editor. Write on the page, retype text, draw shapes, and save a PDF that looks the same everywhere.

Not available for download yet

Mark it up.

Pen, highlighter, and shapes — lines, arrows, rectangles, ellipses and true circles. Every mark can be moved, resized, rotated and erased afterwards.

Change the words.

Add text anywhere, or drag over existing text to cover it and retype it in place. Double-click any text box to edit it again.

Clean when you save.

Everything you draw is merged into the page on save, so the file looks identical in Preview, on iPhone, or on Windows.
